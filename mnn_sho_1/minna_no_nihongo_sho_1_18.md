# ない-form: Prohibition and Obligation

## Grammar

1. **Use case:** Introduce the ない-form (plain negative), the base for the patterns below (Group 1: ます→a-column+ない; Group 2: ます→ない; Group 3: irregular).
   **Pattern:** V（ない形）
   - Example:
     - 書きます → 書かない
     - かきます → かかない
     - write → don't write

2. **Use case:** Tell someone not to do something.
   **Pattern:** V（ない形）でください
   - Example:
     - 心配しないでください。
     - しんぱいしないでください。
     - Please don't worry.

3. **Use case:** State that an action is obligatory (must be done), regardless of the speaker's preference.
   **Pattern:** V（ない形の「い」を取って）ければなりません
   - Example:
     - 薬を飲まなければなりません。
     - くすりをのまなければなりません。
     - I must take medicine.

4. **Use case:** State that an action is unnecessary (doesn't have to be done).
   **Pattern:** V（ない形の「い」を取って）くてもいいです
   - Example:
     - 明日は来なくてもいいです。
     - あしたはこなくてもいいです。
     - You don't have to come tomorrow.

5. **Use case:** Promote an object to topic position with は (replacing を) to contrast or emphasize it, often in negative instructions.
   **Pattern:** N（object）は V
   - Example:
     - 荷物はここに置かないでください。
     - にもつはここにおかないでください。
     - Please don't leave your luggage here.

6. **Use case:** Specify a deadline — "by" a certain time.
   **Pattern:** N（時）までに、〜
   - Example:
     - 土曜日までに本を返さなければなりません。
     - どようびまでにほんをかえさなければなりません。
     - I must return the book by Saturday.
